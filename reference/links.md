## 4. Make 링크에서 확인한 화면 이동 흐름

한 줄 요약: **홈 → (검색창) 검색 결과 → 장바구니 → 결제**이고, 주소 바텀시트는 홈·장바구니·결제에서 열고 저장하면 닫힌다.

| 출발 화면 | 누르는 곳 | 도착 |
|---|---|---|
| 홈 | 검색창 | 검색 결과 |
| 홈 | 헤더 장바구니 · "지난번 주문 그대로 담기 ›" · 하단 "장바구니 N개 보기" | 장바구니 |
| 홈 | 주소 바꾸기 | 주소 바텀시트 |
| 검색 결과 | 뒤로 | 홈 |
| 검색 결과 | 헤더 장바구니 · 하단 "장바구니 N개 보기" | 장바구니 |
| 장바구니 | 뒤로 | 홈 |
| 장바구니 | 다음 품목 검색 | 검색 결과 |
| 장바구니 | "이걸로 바꾸기" / "되돌리기" | 장바구니에 머묾 (대체 전·후 상태 전환) |
| 장바구니 | 하단 "N개 ○원 결제하기" | 결제 |
| 장바구니 · 결제 | 주소 바꾸기 | 주소 바텀시트 |
| 결제 | 뒤로 | 장바구니 |
| 결제 | 하단 "12,860원 결제하기" | 이동 없음 (연결 안 됨) |
| 주소 바텀시트 | 이 주소로 저장 | 시트 닫힘 (원래 화면) |

## 5. 자료끼리 다른 점

우선순위에 따라 위의 자료를 따른다.

| 항목 | 상위 자료 | Make | 따르는 것 |
|---|---|---|---|
| 결제 후 이동 | `10_screens.md` · `14_prototype.md`: 결제하기 → 주문 완료 | 결제하기에 이동이 없고 주문 완료 화면이 없음 | `10_screens.md` (주문 완료로 이동) |
| "지난번 주문 그대로 담기 ›" | `14_prototype.md` 1-3: 지난 주문을 모두 담고 장바구니로 이동 ⚠️ **가정** | 담기 없이 장바구니로만 이동 | `14_prototype.md` |
| 주소 바텀시트 닫기 | 화면 링크·`16_ai-usability.md` 8: 저장 말고 나가는 방법이 보이지 않음 | 저장으로만 닫힘 | 차이 없음. 문제로 남아 있음 |
