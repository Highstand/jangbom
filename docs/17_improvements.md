# 17. 장봄 화면 개선 · 문제 3개와 적용 기록

> **요약:** 페르소나 워크스루와 `16_ai-usability.md`에서 고른 문제 3개(홈 담김 상태, 검색 불가 상품 담기, 마감 예외 안내)를 개선안 A로 고쳤고, 이를 위해 키트 원본(Button·`장봄/마감도착배너`)에 Variant 1개와 속성 2개를 더했다.

## 배경

- **목적:** 워크스루와 휴리스틱 평가에서 나온 문제 중 3개를 골라, 디자인 시스템 안에서 고치고 변경을 기록한다.
- **근거 파일:** `05_persona.md`, `16_ai-usability.md`, `13_design-system.md`, `12_components.md`, `design.md`
- **Figma:** 장봄 UI 화면 섹션(774:1144)
- **진행 순서:** ① 페르소나 워크스루 → ② 문제별 원인 정리 → ③ 문제 3개 선택 → ④ 개선안 선택 → ⑤ Figma 적용
- **표기:** 근거가 없는 판단은 ⚠️ **가정**으로 표시하고 5장에 모았다.

## 1. 워크스루 요약

`05_persona.md`의 김한결이 퇴근길 지하철에서 한 손으로 '지난주에 산 우유와 계란 다시 주문하기'를 해 봤다. 화면에 보이는 것만으로 판단했다.

| 화면 | 막힌 곳 | 연결된 문제 |
|---|---|---|
| 1. 홈 | [담기]를 눌러도 변화가 없어 담겼는지 모름 | 문제 1 (16-2) |
| 3. 검색 결과 | '내일 아침 불가' 상품에도 [담기]가 있어 실수로 담을 수 있음 | 문제 2 (16-5) |
| 4. 장바구니 | 배너는 23:00 마감, 경고는 22:00 마감 지남 | 문제 3 (16-4) |

⚠️ **가정** 워크스루는 Claude가 페르소나를 연기한 결과이며 실제 사용자 테스트가 아니다.

### 선택한 안의 트레이드오프

| 번호 | 얻는 것 | 감수하는 것 |
|---|---|---|
| 1 | 담김 상태가 바로 보이고, 홈·검색 모양이 같아짐(16-9도 함께 해결). 홈의 '장바구니 3개'와 화면이 맞아짐 | 흔들리는 환경에서 +를 잘못 눌러 수량이 늘 수 있음 ⚠️ **가정** |
| 2 | 오지 않는 상품을 담는 실수를 막고, 품절·불가 규칙이 하나로 정리됨 | 회색 버튼만으로는 못 담는 이유를 알 수 없어 배지를 읽어야 함. 다음 행동이 없음(16-11과 같은 약점) |
| 3 | 첫 화면에서 예외 마감을 알 수 있어 23:00·22:00 충돌이 줄어듦 | 어떤 상품인지는 배너만으로 모름. 배너가 28 높아져 아래 배치가 내려감. 장바구니에서는 주황 경고 박스와 내용이 겹침 |

## 4. 남은 할 일

| 항목 | 내용 |
|---|---|
| 장바구니 문구 중복 | 배너 예외 줄과 주황 경고 박스가 비슷한 내용을 두 번 말함. 장바구니에서 예외 줄을 끌지, 경고 박스를 줄일지 정한다 |
| 홈 담기 전 상태 | 홈 프레임이 '담은 뒤' 상태만 보여 줌. 담기 전 상태가 필요하면 프레임을 나눈다 |
| 문서 갱신 | `design.md` 4-1 Button 행(Small Disabled 추가), 4-2 배너 '단일형' 표기, `12_components.md` 2장을 이번 변경에 맞게 고친다 |
| 키트 불일치 기록 | `design.md`는 Button을 "Size × Type × State(Default/Disabled)"로 적었지만 실제 Disabled는 Large·Primary 하나뿐이었다. 이번에 Small·Secondary만 채웠다 |

## 5. 아직 가정인 것

| 번호 | 항목 | 왜 가정인가 | 확인 방법 |
|---|---|---|---|
| 1 | 워크스루 결과 전체 | Claude가 페르소나를 연기한 것이고 실제 사용자 관찰이 아님 | 지하철 환경에서 사용성 테스트 |
| 2 | 홈 수량 조절의 오탭 위험 (문제 1) | 사용자 근거 없음 | 한 손 조작 테스트에서 수량 오입력 관찰 |
| 3 | Disabled 버튼 대비 (문제 2) | `text/disabled`(gray/500)와 `fill/disabled`(gray/300) 대비를 측정하지 않음. Large·Primary·Disabled 조합을 따름 | 대비 측정 |
| 4 | 회색 버튼이 품절로 읽힐 가능성 (문제 2) | 불가와 품절이 배지로만 구분됨 | 사용성 테스트에서 불가 상품 찾기 과제 |
| 5 | 경고 색 사용 (문제 3) | `design.md` 6장에 "경고 색을 쓰는 컴포넌트는 키트에 없음 · 쓸지 정하기"로 남아 있었음 | 키트 담당 확인 |
| 6 | 상품별 마감 데이터 (문제 3) | 상품마다 마감 시각 데이터가 있는지 파일에서 확인하지 못함 | 개발·운영 확인 |
| 7 | 배너 문구 "일부 상품은 22:00 마감이에요" | 마감이 다른 상품이 22:00 하나뿐이라는 전제 | 마감 규칙 정리 후 문구 확정 |
