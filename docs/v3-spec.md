# 장봄 v3 수정 명세 · 검증 핵심 문제 3개

> **요약:** `20_validation-report.md`의 핵심 문제 3개(장바구니 마감 상품, 홈 주소 바꾸기, 결제 금액 불일치)를 `design.md` 규칙과 `12_components.md` 컴포넌트 안에서 고치는 명세다. 새로 필요한 것은 Variant 2개와 속성 1개이고, 새 토큰은 없다.

## 배경

- **근거 파일:** `20_validation-report.md`, `19_test-results.md`, `16_ai-usability.md`, `17_improvements.md`, `design.md`, `12_components.md`, `10_screens.md`
- **참고:** 요청한 `11_design.md`는 프로젝트에 없어 같은 내용인 `design.md`를 기준으로 썼다.
- **표기:** 근거가 없는 판단은 ⚠️ **가정**으로 표시하고 6장에 모았다.
- **범위:** 화면에 없는 기능은 만들지 않고 5장 '추가 제안'으로 나눴다.

## 1. 장바구니 · 마감이 지나 빠지는 상품을 놓침

**원인:** 참가자가 위 4개·아래 3개 불일치로 멈췄고, 원인은 마감으로 빠진 유기농 우유였다(`19_test-results.md`). 배너 예외 줄과 주황 경고 박스가 같은 내용을 두 번 말한다(`17_improvements.md` 4장).

**방향:** 개수는 "4개 중 3개" 한 방식으로, 빠지는 상품은 배지 하나로, 안내는 한 곳에서만.

| 화면 | 바꿀 요소 | 새 상태 · 문구 | 필요한 Variant |
|---|---|---|---|
| 장바구니 | `장봄/마감도착배너` 예외 줄 | `ShowException` 끔. 장바구니에선 경고 박스만 말한다 | 기존 속성 |
| 장바구니 | 주황 경고 박스 (컴포넌트 아님) | "유기농 우유 1개는 22:00 마감이 지나 이번 주문에서 빠져요" | 없음 (문구만) ⚠️ **가정** 22:00은 시안 값 |
| 장바구니 | 불가 상품 위 `장봄/섹션제목` | Title "이번 주문에서 빠지는 상품 1개", `ShowAction` 끔 | 기존 속성 |
| 장바구니 | `장봄/상품카드` Type=Cart, State=Excluded | Details "200mL · 결제에 안 들어가요" ⚠️ **가정** 용량. "삭제" 버튼 유지 | 기존 Variant + Details |
| 장바구니 | 위 카드 안 `장봄/도착배지` | "이번 주문에서 빠짐" · `bg/warning-subtle` / `text/warning` | **새 `장봄/도착배지` State=Excluded** (속성 없음, 문구 고정) |
| 장바구니 | 도착 상품 목록 `장봄/섹션제목` | Title "담은 4개 중 3개 내일 아침 도착" (`10_screens.md` 검색 결과 형식) | 기존 속성 |
| 장바구니 | `장봄/요약카드` 빠지는 상품 ListRow | Label "빠지는 상품" · Value "유기농 우유 · 합계에서 뺐어요" | 기존 속성 |
| 장바구니 | BottomContainer 결제하기 버튼 | "3개 ○원 결제하기" (섹션 제목의 3개와 같게) | 기존 |

## 2. 홈 · 주소 바꾸기 진입점이 안 보이고 엄지가 안 닿음

**원인:** "그냥 글자인 줄 알았어요"(P4), T3 엄격 성공률 40%, 작고 위쪽에 있음(`19`·`20`). 주소 시트 닫기 없음(교차 표 10번)도 함께 고친다.

| 화면 | 바꿀 요소 | 새 상태 · 문구 | 필요한 Variant |
|---|---|---|---|
| 홈 | `장봄/배송지역행` | 줄 전체가 버튼인 카드 한 줄. 라벨 "받는 곳"(`text/tertiary`), 값 "집 · ○○동"(`body/small-strong`), 오른쪽 Button Small·Secondary "바꾸기" + Chevron | **새 `장봄/배송지역행` Type=Row** (기존 = Type=Inline). 358×48 · `bg/card` · `radius/card` · 좌우 16. 속성 `Address`(텍스트), `Label`(텍스트, 기본 "받는 곳") |
| 홈 | 배송지역행 위치 | 위쪽 오른쪽 → `장봄/마감도착배너` 바로 아래, 폭 가득, 카드 간격 12 | 배치 변경 ⚠️ **가정** 엄지 영역 여부는 재테스트로 확인 |
| 홈 | 주소 바꾸기 버튼 | Type Text → Secondary. Primary는 쓰지 않음(`design.md` 5-1) | 기존 Small·Secondary·Default |
| 주소 확인·변경 시트 | 제목 줄 오른쪽 | Icon `close` 추가. 변경 없이 닫힘(`10_screens.md` 2장) | 기존 Header 오른쪽 슬롯 + Icon/close |

## 3. 결제 · 상품 수·금액이 장바구니와 다름

**원인:** 대체 후 장바구니 4개 15,750원 vs 결제 '신선한 우유 외 2개' 12,860원(`16_ai-usability.md` 1번). ⚠️ **가정** 설계 오류인지 프로토타입 연결 탓인지 미확인. 명세는 "결제는 장바구니 최종 상태를 그대로 받는다"는 규칙을 고정한다.

| 화면 | 바꿀 요소 | 새 상태 · 문구 | 필요한 Variant |
|---|---|---|---|
| 결제 | `장봄/요약카드` 주문 상품 ListRow | 장바구니 최종 상태 기준. 예: "신선한 우유 외 3개 · 4개" | 기존 속성 |
| 결제 | `장봄/금액요약` Type=Checkout 합계 | 장바구니 결제하기 버튼 금액과 같은 값 (예: 15,750원) · `heading/h1` · `text/accent` | 기존 Variant |
| 결제 | BottomContainer 결제하기 버튼 | "4개 15,750원 결제하기" (장바구니와 같은 형식) | 기존 |
| 결제 | `장봄/요약카드` (빠진 상품 있을 때만) | ListRow 추가: "빠진 상품" · "유기농 우유 · 결제 안 해요" | **새 속성 `장봄/요약카드` ShowExcluded** (불리언, 기본 꺼짐) |
